## Rouxtine

Native Android trainer for the Roux method (Kotlin, Jetpack Compose, Material 3 Expressive).
Roux only. Start at `docs/HANDOFF.md`.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for `nauroth/rouxtine`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Writing

Run every piece of user-facing text (in-app strings, lessons, store listing, release notes) through the `humanizer` skill.
