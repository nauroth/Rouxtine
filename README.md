# Rouxtine

A native Android trainer for the [Roux method](https://rouxcubing.com/): drills and practice
tools for every stage (first block, second block, CMLL, LSE) and every level. Roux only.

Status: planning. Start with [docs/HANDOFF.md](docs/HANDOFF.md).

## Credits

Rouxtine ports the solver, trainers and alg data of
[onionhoney's Roux Trainers](https://github.com/onionhoney/roux-trainers) (GPL-3.0) to Kotlin.
